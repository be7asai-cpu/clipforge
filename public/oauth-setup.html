Logowanie Google + Facebook

Kod w ClipForge jest gotowy. Ty tylko wklejasz klucze z konsoli Google i Meta do pliku .env, potem restartujesz serwer.

Sprawdzam…

1. BASE_URL (musi być identyczny w .env i w przeglądarce)

http://localhost:3847

Otwieraj Studio pod tym samym adresem (np. localhost, nie mieszaj z 127.0.0.1 — cookie sesji i OAuth się gubią).

2. Google — redirect URI (wklej 1:1 w konsoli Google)

…
  1. Wejdź: Google Cloud → Credentials
  2. Utwórz projekt (np. ClipForge).
  3. OAuth consent screen → External → App name: ClipForge → dodaj swój e-mail jako test user.
  4. Credentials → Create credentials → OAuth client ID → Web application
  5. Authorized JavaScript origins: http://localhost:3847
  6. Authorized redirect URIs: wklej URI Google z góry.
  7. Skopiuj Client ID i Client secret.

3. Facebook — redirect URI

…
  1. Wejdź: Meta for Developers → My Apps
  2. Create App → typ Consumer / Authenticate and request data.
  3. Dodaj produkt Facebook Login → Web.
  4. Settings → Basic: skopiuj App ID i App Secret.
  5. Facebook Login → Settings → Valid OAuth Redirect URIs: wklej URI Facebook z góry.
  6. W trybie Development logują się tylko role (Admin/Developer/Tester) — dodaj siebie w Roles. Na produkcję trzeba App Review (public).
  7. Permissions: email, public_profile (standard).

4. Wklej do pliku .env

BASE_URL=http://localhost:3847

GOOGLE_CLIENT_ID=wklej-tutaj
GOOGLE_CLIENT_SECRET=wklej-tutaj

FACEBOOK_APP_ID=wklej-tutaj
FACEBOOK_APP_SECRET=wklej-tutaj

Plik: C:\Users\londy\Projects\clips-tv\.env — zapisz, potem zrestartuj ClipForge.

Test: odśwież login → przyciski Google/Facebook mają być aktywne (nie szare) → kliknij → po zgodzie wracasz do Studio zalogowany.
